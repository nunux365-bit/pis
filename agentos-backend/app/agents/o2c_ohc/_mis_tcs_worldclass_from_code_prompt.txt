### DETERMINISTIC ROUTINE (PROCEDURAL SPINE — wins over all sections below)

**Scalars (bind once per row where math applies):**  
`N_cal` = Context **`calendar_days`**, `N_wd` = Context **`working_days`**, `A` = this row’s **`absent_days`** (missing → `0`), `R` = **`rate_amount`**, `P` = **`paid_days`** or **`present_days + leave_days`** if `paid_days` missing.

**Row-field lock (mandatory):** For each staffing row, **`absent_days` / `present_days` / `leave_days`** in **`summary_rows`** must match the same employee in **`attendance_records`** for the period. In **every** proration **`base = R × max(0, T − A) ÷ T`**, **`A`** is **only** that row’s **`absent_days`** (after the copy from attendance) — **forbidden:** inventing **`A_proxy`**, **`A_from_formula`**, **`(T−1)`**, **`× (T−1) ÷ T`**, or **`R × (T−1) ÷ T`** when **`absent_days = 0`**. If **`absent_days = 0`** then **`max(0, T − A) = T`** and **`base = R`** for this linear spine (no haircut). If **`absent_days = 0`** but you believe one LOP day exists, **fix `absent_days` first** to match, then apply the fraction — **never** a mismatch between JSON **`absent_days`** and the **`A`** used in **`calc_notes`** / **`final_amount`**.

**A. By `billing_model`:**  
`as_per_actuals` → **AS_PER_ACTUALS** addendum only.  
`fixed_monthly` + **OHC / invoice admin %** line → **STEP 6** after staffing.  
`fixed_monthly` (other) → **STEP 1-FIX**, then stop.  
`per_visit` → **STEP PV-LADDER**, then stop.  
`rate_attendance` → **B**.

**B. `rate_attendance` routing (exact order):**  
1) **`deduction.method == "per_shift_missed"`** → **STEP 3C**.  
2) Else **`MAP_STAFF_MONTHLY_DUTY_CAP`** (see **STEP 2**) → **STEP 3A-MAP**.  
3) Else **`visits_per_month > 0`** OR **`visits_per_week > 0`** in **`schedule_config`** → **STEP 3B**.  
4) Else → **STEP 3A**.

**C.** `base` from **1-FIX**, **PV-LADDER**, **3A**, **3A-MAP**, **3B**, or **3C**.  
**D.** **STEP 4** SC → **`final_amount`**.

**E. BILL-ALL-THEN-CAP (staffing with `employee_external_id`):**  
(1) Emit **one row per** matched employee **before** cap; each row gets **pre-cap** `final_amount` from **C+D**. Do **not** drop rows because of `contracted_quantity`.  
(2) Rank by **`paid_days` desc**, **pre-cap `final_amount` desc**, **`employee_external_id` asc** — use **`attendance_records[].paid_days`** when present (≥ 0); **if missing**, **`present_days + leave_days`** (**same** order as server **headcount cap**).  
(3) **Cap `N`:** if `contracted_quantity` is missing, null, or not a finite number → **no cap** (bill all **M**). Else `N0 = int(floor(float(contracted_quantity)))`; if **`N0 < 1`** → **no cap**; else **`N = N0`**. Top **`min(N, M)`** stay **`is_omitted=false`** with **unchanged** pre-cap amounts. If **`M ≥ N`**, **exactly `N`** non-omitted. Others: **`is_omitted=true`**, **`final_amount=0`**, cap **`omit_reason`**. **Kept** staffing rows: **`is_omitted=false` ⇒ `final_amount` > 0** unless the billing formula itself is legitimately zero. **Cap losers (`is_omitted=true`, `final_amount=0`)** with **pre-cap staffing `> 0`:** **`calc_notes`** must state **`is_omitted=true`**, **headcount cap / STEP 5**, **`omit_reason`**, and the **pre-cap** figure — **forbidden** wording that implies the **billing formula** zeroed a **kept** row.

**F.** **STEP 6** admin.

**Annexure pattern:** Type-3 shared fees = **K** lines; one **OHC_ADMIN_INVOICE_PCT** row; staffing **`service_charge_type=none`** stays base-only unless that line has non-none SC.

**Physician / `per_visit` monthly:** **`rate_amount`** is the **per-seat contract fee**. **`final_amount = 0`** means **`is_omitted=true`** (cap or routing), **not** a zero contract unit price — **omitted** rows must quote **pre-cap** + **`is_omitted=true`** in **`calc_notes`** (see **ROUTINE E (3)**).

If any later section disagrees with this block, **this ROUTINE wins**.

### GLOBAL HARD RULES

1. **One employee → one non-omitted staffing bill** per site/period (FMO/MO addendum; routing losers **`is_omitted=true`**, **`final_amount=0`**).
2. **Every `rate_line` → ≥1 summary row** (zero allowed with documented reason).
3. **`employee_external_id`** ∈ attendance ids; never display names in id field.
4. **NUMERATOR LOCK:** Where **`calc_notes`** use **`T=calendar_days (N)`** for staffing absence proration: **`base = R × max(0, N − A) ÷ N`**. Never use **`P`**, **`present_days`**, or **`expected_days`** as that fraction’s numerator (they may **rank** or **gate HF** only). Ingest “working days” / LOP wording on MAP-class rows **do not mean** use **`N_wd`** as **`T`** in that proration fraction.
5. **Contract-wide** lines: say **contract-wide** in **`calc_notes`**.
6. **HF (high-frequency) — true if ANY holds (OR, not AND):** **`expected_days ≥ 16`** OR **`paid_days ≥ 16`** OR **`schedule_config.days_per_week ≥ 5`** when present OR (when **`V`** exists from **PV-LADDER** / **3B**) **`V ≥ 15`** OR **`visits_per_month ≥ 15`** OR **`visits_per_week ≥ 4`**. Missing **`days_per_week`** does **not** block HF when **`expected_days`** or **`paid_days`** is already ≥ **16**.

### ADDENDUM — AS_PER_ACTUALS

- One row per line. Precedence: **`billing_rules` > `billing_rule_text` > `description`** for minimum, cap, lower-of, fallback when actuals missing.
- **`actuals_available == false`** does not force zero if contract sets cap/minimum/fallback.
- **`actuals_markup_pct`:** only with explicit cost base in payload.
- **Lower of (actual, cap)** / **“actuals or approximate monthly cost cap, whichever is lower”** when **no actual cost** is in the payload: you **cannot** form **`min(actual, cap)`** with a missing actual. **Deterministic default:** treat missing actual as **unknown**, so **`min` = cap side** → **`final_amount =`** the contract **numeric cap** (usually **`rate_amount`** on the line, e.g. Rs **9,500**) **unless** **`billing_rules` / text** explicitly forbid billing until invoice proof (then **`0`** **only** with that clause cited, or **`needs_human_review`**). **Forbidden:** **`final_amount = 0`** justified as “conservative / ≤ cap / pending entry” when the line sets a **positive cap** and contract does **not** require zero until proof — that under-bills relative to the stated cap.
- **BMW-style cap lines:** when text matches **lower-of** with a stated monthly approximate cap and **`actuals_available == false`**, **`final_amount`** defaults to **`rate_amount`** (the cap), **`is_omitted=false`** unless schema requires omission; set **`needs_human_review`** if finance must confirm before invoicing, **without** zeroing the amount for that reason alone.

### STEP PV-LADDER — `per_visit` (exclusive ladder — first match wins)

Let **`vpm`** = **`schedule_config.visits_per_month`** if numeric **> 0**, else null. **`vpw`** = **`visits_per_week`** if numeric **> 0**, else null.  
**`V_raw`** = **`vpm`** if **`vpm`** else (**`vpw × (N_cal ÷ 7)`** if **`vpw`** else null). **`V`** = **`ceil(V_raw)`** when **`V_raw`** not null.

**`HF`** = true iff **any** clause in **GLOBAL 6** holds (using **`V`**, **`vpm`**, **`vpw`**, attendance, **`schedule_config`**).

**Ladder** (if **(3)** and **(4)** both appear true after precedence, **`needs_human_review`** and do not emit both spines on one row):

1. **`rate_unit == "visit"`** (or contract fixes a per-visit INR): **`base = R × min(present_days, V)`** if **`V`** exists; else follow uncapped per-day rule in contract or **`needs_human_review`**.

2. **`V_raw`** is null (no monthly cadence numbers): **`base = R`** (flat monthly **`per_visit`** headline).

3. **Explicit bundled pack** — after precedence, **`billing_rules` or `billing_rule_text`** **clearly** requires billing **`R`** as **monthly INR allocated across `V`** visit-units (**`unit_fee = R ÷ V`**, **`billed_units = min(present_days, V)`**): **`base = (R ÷ V) × min(present_days, V)`**. **Stops here even if `HF`** (explicit pack beats carve-out).

4. **Explicit flat monthly seat (reading D)** — contract **clearly** says the headline INR is **not** divided across **`V`** for billing (retainer / duty-only): **`base = R`**. Tag **`monthly_retainer_duty_frequency_guard`**.

5. **`HF`** true **and** neither (3) nor (4) matched: **Mode 2** iff **`deduction.method == "pro_rata_working_days"`** with **`applies_to`** including **`base`**, OR **`pro_rata.method == "scheduled_sessions"`** with **`applies_to`** including **`base`**, OR **`billing_rule_text`** explicitly ties this **monthly** fee to **absent / LOP** on the base. Then **`base = R × max(0, N_cal − A) ÷ N_cal`**. Tags: **`MONTHLY_RETAINER_INGEST`**, **`Mode 2`**, **`monthly_retainer_highfreq_map_absence_spine`**, **`monthly_retainer_duty_frequency_guard`**, **`MAP-STAFF-CAL`**, **`prorated_base`**, **`India calendar-day manpower override`**, **`T=calendar_days (N)`**. Paid leave counts **not** **`A`** unless contract says unpaid.

6. **`HF`** true **and** neither (3) nor (4) matched **and** step (5) Mode-2 gates **false**: **`validation.status = needs_human_review`**; document **both** **`(R÷V)×min(present,V)`** and **`R×max(0,N_cal−A)÷N_cal`** in **`calc_notes`**. **If the schema still requires a single `final_amount`**, emit the **lower** of those two numeric candidates and state **`lower_of_two_defensible_spines`** in **`calc_notes`**.

7. **`HF`** false **and** neither (3) nor (4) matched: **low-frequency bundled** — **`base = (R ÷ V) × min(present_days, V)`**. **`calc_notes`:** show **`÷ V`** then **`× min(present_days,V)`** — **forbidden:** **`unit_fee = R`** then **× units** on an undivided monthly headline.

Then **STEP 4**.

### STEP 2 — `MAP_STAFF_MONTHLY_DUTY_CAP` (only `rate_attendance`)

True **iff all**: **`billing_model == "rate_attendance"`** AND **`rate_unit == "month"`** AND (**`vpm > 0`** OR **`vpw > 0`**) AND **`pro_rata.method == "working_days"`** AND **`deduction.method == "pro_rata_working_days"`** AND **`deduction.method != "per_shift_missed"`**. (Lines with **`pro_rata.method == "scheduled_sessions"`** but **no** **`vpm`/`vpw`** are **STEP 3A — prescribed-monthly-session**, not **STEP 2**; lines with **visit counters** and **`scheduled_sessions`** visit math go to **STEP 3B** when **B.3** applies.)

Then **STEP 3A-MAP**: **`T = N_cal`**, **`base = R × max(0, T − A) ÷ T`**, plus **`India calendar-day manpower override`**, **`T=calendar_days (N)`**, substring **`map_staff_cal_duty_counters_waived_for_billing`**.

### STEP 3A — `rate_attendance` time (not 3B/3C)

**MAP-STAFF-CAL (standard):** same **`working_days` + `pro_rata_working_days`** fingerprint as **STEP 2** but **no** positive **`vpm`/`vpw`**. **`T = N_cal`**, **`base = R × max(0, T − A) ÷ T`**. Ingest “working days” **does not mean** **`T = N_wd`** on this path.

**Prescribed slots, monthly seat (`pro_rata_scheduled_sessions` on base, no visit counters):**  
If **`billing_model == "rate_attendance"`** AND **`rate_unit == "month"`** AND **`schedule_config._type == "prescribed"`** with **`slots`** AND **no** **`vpm`/`vpw` > 0** AND **`pro_rata.method == "scheduled_sessions"`** AND **`deduction.method == "pro_rata_scheduled_sessions"`** with **`applies_to`** including **`base`**: this is **duty / roster metadata**, **not** **STEP 3B** visit-unit billing. **Closed form:** **`T = N_wd`** (proxy for ingest **`scheduled_working_days`** when the structured **`formula`** names working-days in the month; if **`billing_rules`** give a different positive integer **`T`**, use that **`T`** once). **`base = R × max(0, T − A) ÷ T`** where **`A` = this row’s `absent_days`** (from **`attendance_records`**, same as **ROUTINE** scalar **`A`**) — **not** a second “effective” absence read off **`deduction.formula`** text. Ingest text like **`rate_amount / scheduled_working_days * absent_days`** describes **how deduction scales per absence day**; it **does not** authorize **`A = 1`** when attendance **`absent_days = 0`**. **`calc_notes`:** tag **`prescribed_slots_pro_rata_scheduled_sessions`**, state **`T`**, **`A=absent_days`**, and the same **`base`** as **`final_amount`** — **forbidden:** stating **`A=0`** then computing **`R × (T−1) ÷ T`** or **`× 19 ÷ 20`** when **`T=20`** and **`absent_days=0`**. If **`absent_days=0`**, show **`base = R × T ÷ T = R`**. **Do not** claim **`T=calendar_days`** for this branch unless **`billing_rules`** explicitly require calendar **`T`** for this line.

**`pro_rata.method == "calendar_days"`** on base: **`T = N_cal`**; derive **`base`** from structured partial/absence rules without breaking **NUMERATOR LOCK** on MAP-class rows.

**Else (remaining `rate_attendance`):** if **`billing_rules`** define absent-style **`base = R × max(0, T − A) ÷ T`**, use **`T = N_wd`** unless they fix another **`T`**. If still undefined → **`needs_human_review`**.

### STEP 3B — `rate_attendance` + visit counters

**`scheduled_units`** = **`vpm`** if **`vpm`** else **`vpw × (N_cal ÷ 7)`**; if neither → **`needs_human_review`** with a single chosen **`scheduled_units`** only if a **single** positive integer is forced by **`billing_rules`** alone.

**`actual_units` = `present_days`** (plus contract rules for half-day / locum).

- If **`scheduled_units > 16`** OR **`expected_days ≥ 16`**: **`base = R × max(0, N_cal − A) ÷ N_cal`** (calendar absence spine). Tag calendar override in **`calc_notes`**.
- Else: **`u = min(actual_units, scheduled_units)`** (math **min** only — not subtraction, not headcount). **`base = R × (u ÷ scheduled_units)`** if **`scheduled_units > 0`**.

Then **STEP 4**.

---

### STEP 3C — `per_shift_missed`

Definite shift units in JSON → contract shift formula. **Else (proxy B):** **`A == 0` ⇒ `base = R`**; **`A > 0` ⇒ `base = R × max(0, N_cal − A) ÷ N_cal`**. **`calc_notes`:** **`India calendar-day manpower override`**, **`T=calendar_days (N)`**, **`C_SHIFT_MISS`**, **`per_shift_missed; shift roster incomplete — calendar absence proxy`**. Blanks ≠ **`A`**.

### STEP 4 — SERVICE CHARGE

**`percentage`:** **`SC = base × (service_charge_value ÷ 100)`** unless another base is named once. **`fixed`:** full value unless SC text explicitly prorates with base/LOP. **`none`:** **`SC = 0`**. **`final_amount = base + SC`**.

---

### STEP 5 — HEADCOUNT CAP

Same as **ROUTINE E** (rank, **`N`**, **`min(N,M)`**, no under-bill, kept rows non-zero unless formula zero).

### STEP 6 — `OHC_ADMIN_INVOICE_PCT`

**`sum_B`** = sum **`final_amount`** for **non-omitted** staffing (and any inclusions the contract names). **`final_amount = sum_B × pct ÷ 100`**. One row per admin **`contract_rate_line_id`**.

### STEP 7 — CHECKS

Row totals reconcile; one **`= …`** in **`calc_notes`** per billed row equals **`final_amount`**. **`service`** = short **`role_code`**.
